## 一、设计理念

校园失物招领 App 的界面延续 Claude 系"温暖人文"审美：以 Parchment 暖纸色为画布，营造纸张而非屏幕的质感；以 Terracotta 陶土色为品牌主色，传递"可靠、可亲近、有人情味"的互助社区氛围。在此基础上叠加校园场景语义：圆润卡片、柔和阴影、状态色清晰，让"找到失物"这件事始终温暖而不慌乱。

**关键词**：温暖 · 人文 · 可信 · 互助 · 圆润 · 柔和 · 纸张质感

**设计基调**：
- 暖色画布 + 暖色中性灰：全部灰色带黄棕底色，不使用冷蓝灰
- 衬线标题 + 无衬线 UI：标题有书卷气，界面信息高效
- ring shadow 深度体系：交互反馈用环形阴影而非生硬描边
- 状态语义色保持暖色调性：认领相关状态一目了然且不刺眼

- 允许场景性极轻微渐变：如 Banner 区 Terracotta → Coral（0~10% 透明度渐变），用于告示横幅视觉区分
- 卡片、图片使用柔和圆角与 whisper 阴影营造"纸张浮起"感

## 三、字体与排版

### 3.1 字体体系（中文字体 + HarmonyOS 回退）

| 角色 | 字体 | 回退 |
|------|------|------|
| 标题 | 思源宋体 `Noto Serif SC` | `serif` |
| 正文 / UI | 思源黑体 `Noto Sans SC` | `HarmonyOS Sans SC` → `sans-serif` |
| 数字 / 时间 | `HarmonyOS Sans` 数字字形 | 系统默认 |

> HarmonyOS 设备优先使用系统内置 `HarmonyOS Sans SC`；标题宋体缺失时回退 `serif`，保证人文感不丢失。

### 3.2 排版层级（sp 单位，适配 ArkUI）

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| Display | 28sp | 600 | 1.2 | 页面大标题、空状态主文案 |
| Heading 1 | 24sp | 600 | 1.3 | 页面标题、详情页物品名 |
| Heading 2 | 20sp | 500 | 1.3 | 区块标题、卡片标题 |
| Subtitle | 16sp | 500 | 1.4 | 卡片内小标题、Tab 标签 |
| Body | 16sp | 400 | 1.6 | 正文、物品描述 |
| Body Small | 14sp | 400 | 1.5 | 辅助说明、输入提示 |
| Caption | 12sp | 400 | 1.4 | 时间、元数据、计数 |
| Label | 11sp | 500 | 1.3 | 标签、徽章文字 |
| Micro | 10sp | 400 | 1.4 | 最小字号（慎用） |

**排版原则**：
- 标题用宋体衬线传达人文感，正文用黑体保证信息效率
- 正文行高 ≥ 1.5，营造舒适阅读节奏
- 标题字重上限 600，不滥用粗体
- 数字与时间使用等宽数字字形对齐（如"12:30"）

## 四、间距、圆角与深度体系

### 4.1 间距系统

- 基础单位：**8sp**（ArkUI 中对应 `vp`）
- 常用间距：2 · 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40
- 卡片内边距：16~24vp；页面左右安全边距：16vp
- 底部导航上内容留白 ≥ 88vp（避开手势区）

### 4.2 圆角体系

| 档位 | 圆角 | 用途 |
|------|------|------|
| Sharp | 4vp | 内联元素、小标签 |
| Rounded | 8vp | 标准按钮、小卡片 |
| Generous | 12vp | 输入框、主按钮、Tab 容器 |
| Feature | 16vp | 动态卡片、弹窗 |
| Hero | 24vp | 大图卡片、Banner |
| Full | 28vp+ | 图片容器、头像（圆形） |

### 4.3 深度与阴影（沿用 ring shadow 体系）

| 层级 | 效果 | 用途 |
|------|------|------|
| Flat (L0) | 无阴影无描边 | 页面背景、内联文字 |
| Contained (L1) | `1px solid #F0EEE6` | 标准卡片、分组容器 |
| Ring (L2) | `0 0 0 1px #D1CFC5` 环形阴影 | 可交互卡片、按钮悬停/按下 |
| Whisper (L3) | `rgba(0,0,0,0.05) 0 4vp 24vp` | 浮起卡片、弹窗、下拉面板 |
| Inset (L4) | `inset 0 0 0 1px`（15% 不透明） | 按钮按下态、选中态 |

> 深色模式下描边与环形阴影使用 `#30302E` 系暖黑，不使用冷灰。

## 五、组件规范

### 5.1 按钮

| 变体 | 背景 | 文字 | 圆角 | 用途 |
|------|------|------|------|------|
| 主按钮（Primary） | `#C96442` | `#FAF9F5` | 12vp | 发布、提交、确认等主操作 |
| 次按钮（Secondary） | `#E8E6DC` | `#4D4C48` | 8vp | 取消、返回、次要操作 |
| 白面按钮（White） | `#FFFFFF` | `#141413` | 12vp | 浅色浮层上的操作 |
| 深色按钮（Dark） | `#30302E` | `#FAF9F5` | 12vp | 深色模式主操作 |
| 文字按钮（Text） | 透明 | `#C96442` | - | 跳转、次级链接 |
| 危险按钮（Danger） | `#B53333` | `#FAF9F5` | 12vp | 删除、注销、举报提交 |

- 高度：主操作 ≥ 44vp（触控标准）；行内按钮 ≥ 36vp
- 按下态：Inset 环形阴影 + 轻微缩放（scale 0.97）
- 禁用态：背景降为 `#E8E6DC`、文字 `#B0AEA5`

### 5.2 动态卡片（失物 / 寻物）

结构（自上而下）：

```
[发布者头像 + 昵称] [状态标签] [相对时间]
物品名称（Heading 2，宋体 600）
物品描述（Body，两行截断 + "…"）
[图片首图缩略图 16:10]
[拾获/丢失地点（图标 + 文字）] [分类标签]
[互动栏：评论 点赞 转发]  [认领/线索主按钮]
```

- 背景 `#FAF9F5`，圆角 16vp，描边 `#F0EEE6`
- 状态标签左上角（或标题行右端），按 2.2 语义色
- 卡片点击进入详情；认领/线索按钮为主按钮变体
- 加急动态卡片左上角叠加"急"红色角标（`#B53333`），文字 `#FAF9F5`

### 5.3 状态标签（Tag）

| 类型 | 底色 | 文字色 |
|------|------|--------|
| 待认领 | `#C9923E` 12% | `#C9923E` |
| 认领中 | `#6E8B5E` 12% | `#6E8B5E` |
| 已归还 / 已找回 | `#5E8B5E` 12% | `#5E8B5E` |
| 已关闭 | `#87867F` 12% | `#87867F` |
| 加急 | `#B53333` | `#FAF9F5` |
| 悬赏 | `#C9923E` 12% | `#C9923E` |
| 分类 | `#E8E6DC` | `#4D4C48` |

- 圆角 4vp，内边距 `4vp 8vp`，文字 Label 11sp/500

### 5.4 信用等级徽章

- 等级 1~5 对应称号：新人 / 热心同学 / 校园达人 / 失物克星 / 校园守护者
- 展示于个人主页头像旁与动态卡片发布者行
- 样式：圆形徽章（深底 `#30302E` + 星级）+ 称号文字；等级 ≥ 4 增加 Terracotta 描边

### 5.5 发布表单

| 元素 | 规范 |
|------|------|
| 输入框 | 背景 `#FFFFFF`，描边 `#E8E6DC`，圆角 12vp，内边距 12vp 16vp |
| 焦点态 | 描边切 `#3898EC`（唯一冷色） |
| 错误态 | 描边切 `#B53333` + 错误文案 Caption |
| 标签 | 表单标签用 Subtitle 500，必填项加 `*`（Terracotta） |
| 照片选择 | 9 宫格网格，+号占位按钮（sand 底）；单张 ≤ 10MB |
| 提交按钮 | 主按钮通栏（占满宽度），加载态转圈 |

### 5.6 底部导航

- 5 个 Tab：首页 / 动态（失物+寻物）/ 发布（中央突出）/ 消息 / 我的
- 选中态：图标 + 文字 Terracotta；未选中：Stone Gray
- 中央发布按钮：48vp 圆形 Terracotta + 白 "+" 图标，带 whisper 阴影
- 消息 Tab 未读角标：红点（≥1 未读）/ 数字（≥100 显示"99+"）

### 5.7 弹窗与对话框

| 类型 | 规范 |
|------|------|
| 确认弹窗 | 卡片 `#FAF9F5`，圆角 16vp，标题 Heading2 + 说明 Body + 双按钮 |
| 底部操作面板 | 圆角 24vp（顶部圆角），支持下滑关闭，遮罩 40% 黑 |
| 危险操作确认 | 二次确认，按钮用 Danger 变体，文案明示后果 |
| Toast | 深底 `#30302E` 圆角 12vp，文字 `#FAF9F5`，底部居中，2 秒自动消失 |

### 5.8 空状态与加载

- 空状态：居中插画 + 标题（Display 28sp 宋体）+ 说明（Stone Gray）+ 行动按钮
- 加载：骨架屏（Parchment → Ivory 呼吸闪烁）优先于转圈
- 下拉刷新：Terracotta 圆点指示器

### 5.9 消息列表与私信

- 会话列表：头像 + 昵称 + 最后一条消息（两行截断）+ 时间 + 未读圆点
- 私信气泡：本人 `#C96442` 底白字；对方 `#FFFFFF` 底深字（圆角 16vp）
- 时间分组：今天 / 昨天 / 更早（Stone Gray 标签）

## 六、动效与交互反馈

| 场景 | 动效 | 时长 / 参数 |
|------|------|-------------|
| 页面转场 | 右滑进入 + 缩放淡入 | 300ms / cubic-bezier(0.2,0,0,1) |
| Tab 切换 | 内容淡入 + 轻微上移 | 200ms |
| 点赞 / 收藏 | 图标弹跳 + 变色（灰 → Terracotta） | 150ms / scale 1.2 回弹 |
| 卡片按压 | 缩放 + Inset 阴影 | 100ms / scale 0.98 |
| 下拉刷新 | 指示器旋转 + 弹簧回弹 | 300ms |
| Toast | 底部上滑进入 | 200ms 进入，2s 停留，200ms 退出 |
| 骨架屏 | 呼吸闪烁 | 1.2s 循环 |
| 状态变更 | 标签切换 + 轻提示 | 200ms |

**原则**：动效服务于信息反馈，不使用弹跳式夸张动画；所有动效尊重系统"减少动态效果"设置。

## 七、深色模式与无障碍

### 7.1 深色模式映射

| 浅色 token | 深色 token |
|------------|------------|
| `bg.parchment` `#F5F4ED` | `bg.deep_dark` `#141413` |
| `bg.ivory` `#FAF9F5` | `bg.dark_surface` `#30302E` |
| `bg.sand` `#E8E6DC` | `#3D3D3A` |
| `border.cream` `#F0EEE6` | `#30302E` |
| `text.near_black` `#141413` | `text.warm_silver` `#B0AEA5` |
| `text.olive` `#5E5D59` | `#87867F` |
| 状态语义色 | 提亮 10%~15% 保证对比度 |

- 品牌主色 Terracotta 在深色模式保持原值；按钮文字切 `#FAF9F5`
- 深色模式由系统或设置页切换，全局即时生效

### 7.2 无障碍

- 正文 / 辅助文字与背景对比度 ≥ 4.5:1（WCAG AA）
- 触控目标最小 44×44vp
- 所有图标组件附文字标签（无障碍播报）
- 支持系统字体缩放（动态字号，1.0~1.3 倍）
- 状态语义不单靠颜色表达：加急标签同时含"急"文字，状态标签含文字

## 九、Do's and Don'ts

### Do
- 使用 Parchment `#F5F4ED` 作为主背景，Ivory `#FAF9F5` 承载卡片
- 主操作统一使用 Terracotta `#C96442`，品牌时刻才使用
- 所有中性灰保持暖色底（黄棕色调），禁止冷蓝灰
- 标题用宋体（Noto Serif SC），正文用黑体（Noto Sans SC / HarmonyOS Sans SC）
- 状态用语义色标签表达：待认领琥珀、认领中暖绿、已归还深绿、加急深红
- 交互反馈使用 ring shadow / whisper shadow，而非生硬 drop shadow
- 圆角至少 8vp，主卡片 16vp，营造圆润亲和感
- 触控目标 ≥ 44×44vp，正文行高 ≥ 1.5

### Don't
- 不要使用冷色系灰色与蓝色（焦点色 `#3898EC` 除外）
- 不要用纯白 `#FFFFFF` 作页面背景
- 不要使用锐利直角（< 6vp）承载主要交互

- 不要忽略系统"减少动态效果"设置
