## 一、启动后端

### 1.1 首次初始化数据库（仅在重置时需要）

```bash
cd D:\HarMonyProjectPath\Found\server
npm install        # 已装过可跳过
npm run seed       # 建表 + 写入种子数据（幂等，可重复执行）
```

`seed` 会重建/补全 11 张表并写入：4 个演示用户、24 条动态、评论/点赞/收藏/认领/线索/私信/积分/举报/分类。重复执行安全。

### 1.2 启动服务

```bash
cd D:\HarMonyProjectPath\Found\server
npm start
```

看到日志 `found-server listening on http://0.0.0.0:3000` 即成功。

### 1.3 验证

浏览器或 curl 打开：`http://127.0.0.1:3000/api/health`

应返回：
```json
{"code":0,"message":"ok","data":{"ok":true,"time":"..."}}
```

> **注意**：后端要在**独立终端**里保持运行（别关窗口）。关掉后 App 就取不到数据。

## 二、配置前端 BASE_URL（关键一步）

文件：`entry/src/main/ets/shared/api/HttpClient.ets`

```ts
/** 本地模拟器/预览器地址；真机联调改为 PC 局域网 IP */
export const BASE_URL: string = 'http://127.0.0.1:3000';
```

| 运行目标 | BASE_URL 建议 |
|----------|---------------|
| DevEco 模拟器 | `http://127.0.0.1:3000`（模拟器与宿主机共享网络时可用）；不行就换 PC 局域网 IP |
| 真机 | `http://<PC局域网IP>:3000`，如 `http://192.168.1.5:3000` |
| DevEco 预览器 | 不一定支持真实网络请求，见常见问题 |

**查看 PC 局域网 IP**（终端执行）：

```powershell
ipconfig
```

找「无线局域网适配器 / 以太网适配器」下的 `IPv4 地址`（形如 `192.168.x.x`，不是 `127.0.0.1`、不是 `169.254.x.x`）。

改完 BASE_URL 后，在 DevEco 重新 Run 一次（会自动重新编译）。

## 三、前端运行（推荐：DevEco Studio）

1. 打开 DevEco Studio → `File > Open` 选择 `D:\HarMonyProjectPath\Found`
2. 等待工程 Sync 完成
3. 选择运行目标：
   - **模拟器**：`Tools > Device Manager` 启动一个模拟器（推荐，能访问后端）
   - **真机**：手机开启开发者模式 + USB 调试，连接电脑
4. 顶部点 **Run ▶**（自动签名 + 编译 + 安装 + 启动）

> 首次真机运行会提示登录华为账号做自动签名，按提示操作即可。

## 五、常见问题排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 首页空白 / 无数据 | 后端没启动 | 确认 `npm start` 在跑；浏览器访问 health 验证 |
| 登录报「网络异常」 | BASE_URL 不对 / 端口不通 | 检查 BASE_URL；`ipconfig` 确认 IP；`curl http://<IP>:3000/api/health` 测通 |
| 真机连不上 | 不在同一网段 / 防火墙拦截 | 手机与 PC 连同一 WiFi；放行 3000 端口入站 |
| 预览器（Previewer）连不上后端 | 预览器是 UI 沙箱，可能发不了真实网络请求 | **改用模拟器或真机验证**，预览器只看静态布局 |
| 发布后首页看不到 | 动态在待审核状态 | 用管理账号在「管理后台 → 信息审核」通过 |
| 管理后台进不去 | 当前登录非管理员 | 用 `13800000001 / admin123` 登录 |

## 六、后端独立验证（可选，用 curl）

```bash
# 登录拿 token
curl -X POST http://127.0.0.1:3000/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"phone":"13800000002","password":"123456"}'

# 动态列表
curl "http://127.0.0.1:3000/api/posts?page=1&size=3"

# 带 token 调受保护接口（把 <TOKEN> 换成登录返回的 token）
curl http://127.0.0.1:3000/api/auth/me -H "Authorization: Bearer <TOKEN>"
```

完整接口见 `docs/API.md`。
