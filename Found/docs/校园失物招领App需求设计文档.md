# 校园失物招领 App — 产品需求设计文档

> 面向在校大学生的校园失物招领平台，参考主流社交类 App 交互模式，融合校园场景特色功能。

---

## 一、产品概述

### 1.1 产品定位

一款面向高校师生的校园失物招领平台，解决校园内物品丢失后信息不对称、找回率低的问题。以"发布-匹配-互动"为核心流程，融入社区化互动机制，提升失物归还效率。

### 1.2 目标用户

| 用户角色 | 说明 |
|----------|------|
| 学生 | 在校本科生、研究生，主要使用群体 |
| 教师 | 在校任课教师、辅导员 |
| 教职工 | 行政人员、后勤人员、安保人员 |
| 系统管理员 | 学校信息中心指定人员，负责审核与管理 |

### 1.3 核心价值

- **失主**：快速发布寻物信息，精准匹配拾获信息，提高找回概率
- **拾获者**：便捷发布拾获信息，通过平台联系失主，完成归还
- **学校**：规范失物招领流程，减少管理成本，提升校园服务体验

## 三、详细功能需求

### 3.1 模块一：用户管理

#### 3.1.1 注册

| 项目 | 说明 |
|------|------|
| 注册方式 | 手机号注册（优先）、学校邮箱注册 |
| 身份选择 | 学生 / 教师 / 教职工，注册时选择 |
| 学生认证 | 学号 + 姓名 + 所在院系 + 入学年份 |
| 教师认证 | 工号 + 姓名 + 所在院系 |
| 教职工认证 | 工号 + 姓名 + 所属部门 |
| 密码规则 | 8~20位，含字母和数字 |
| 验证码 | 手机短信验证码 / 邮箱验证码 |
| 协议 | 需同意《用户协议》和《隐私政策》 |

#### 3.1.2 登录

| 项目 | 说明 |
|------|------|
| 登录方式 | 手机号+密码、手机号+验证码、学校邮箱+密码 |
| 第三方登录 | 预留华为账号登录接口（可选扩展） |
| 自动登录 | 支持Token自动续期，7天内免登录 |
| 登录失败提示 | 账号不存在、密码错误、账号已冻结等明确提示 |
| 多设备登录 | 同一账号仅允许一台设备同时在线，新登录挤掉旧登录 |

#### 3.1.3 个人信息管理

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 头像 | 否 | 默认根据角色生成头像 |
| 昵称 | 是 | 2~16个字符，不可重复 |
| 真实姓名 | 是 | 认证时填写，他人不可见 |
| 学号/工号 | 是 | 认证时填写，他人不可见 |
| 院系/部门 | 是 | 对外展示 |
| 年级（学生） | 是 | 如"2024级" |
| 联系方式 | 否 | 手机号/微信，发布动态时可选择是否展示 |
| 校区 | 是 | 主校区/分校区，用于区域筛选 |

#### 3.1.4 账号安全

- 修改密码（需验证原密码或手机验证码）
- 绑定/换绑手机号
- 绑定/换绑邮箱
- 账号注销（需确认无未完结的失物/寻物记录）

| 衣物配饰 | 👕 | 外套、围巾、帽子、手套、雨伞、书包 |
| 运动器材 | ⚽ | 球类、球拍、滑板、瑜伽垫 |
| 生活用品 | 🎒 | 水杯、眼镜、化妆品、药品 |

#### 3.2.3 智能搜索

| 功能 | 说明 |
|------|------|
| 关键词搜索 | 支持物品名称、地点、描述等关键词模糊搜索 |

| 搜索建议 | 输入时实时联想补全 |

#### 3.2.4 筛选与排序

| 筛选维度 | 选项 |
|----------|------|
| 物品分类 | 一级分类 + 二级分类级联选择 |
| 丢失/拾获地点 | 教学楼、食堂、图书馆、宿舍区、操场、校门口、其他 |

| 状态 | 待认领 / 认领中 / 已归还 / 已关闭 |
| 校区 | 主校区 / 分校区 |

| 排序方式 | 说明 |
|----------|------|
| 最新发布 | 按发布时间倒序 |
| 距我最近 | 按丢失/拾获地点距当前位置距离排序 |
| 最热动态 | 按互动量（评论+点赞）排序 |

### 3.3 模块三：失物动态

> 场景：我捡到了别人丢失的物品，想发布信息帮其找回。

#### 3.3.1 失物发布

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 物品分类 | 是 | 一级+二级分类选择 |
| 物品名称 | 是 | 简短描述，如"华为Mate60手机" |
| 物品描述 | 是 | 详细描述物品特征（颜色、型号、破损等），10~500字 |
| 拾获地点 | 是 | 地图选点+文字描述，如"图书馆3楼A区302" |
| 拾获时间 | 是 | 日期+时段选择 |
| 物品照片 | 是 | 1~9张照片，必须至少1张；支持拍照/相册选取 |
| 联系方式 | 是 | 选择展示方式：App内私信 / 手机号 / 微信号 |
| 当前存放地 | 否 | 物品暂存位置，如"交到保卫处前台" |
| 悬赏状态 | 否 | 发布者可选择是否愿意提供感谢金 |
| 匿名发布 | 否 | 默认实名，可切换匿名（认证信息后台可见） |

**发布流程**：

```
选择分类 → 填写信息 → 上传照片 → 预览确认 → 提交审核 → 审核通过 → 发布上线
```

#### 3.3.2 失物动态列表

每条动态卡片展示：

| 元素 | 说明 |
|------|------|
| 发布者头像+昵称 | 点击可查看发布者主页 |
| 发布时间 | 相对时间（刚刚、5分钟前、1小时前、昨天、日期） |
| 物品标签 | 分类标签 + 状态标签（待认领/认领中/已归还） |
| 物品名称 | 粗体显示 |
| 物品描述 | 截取前两行，超出显示"..." |
| 物品照片 | 第一张缩略图，点击查看全部 |
| 拾获地点 | 图标+文字，点击可打开地图 |
| 互动栏 | 评论数 / 点赞数 / 转发数 |
| 认领按钮 | "这是我的"入口 |

#### 3.3.3 互动功能

**评论**：

| 功能 | 说明 |
|------|------|
| 发表评论 | 文字评论，最多 200 字 |
| 回复评论 | 支持对评论进行回复，形成楼中楼（最多2层嵌套） |
| 删除评论 | 仅可删除自己的评论 |
| 举报评论 | 举报不良评论，提交管理员审核 |

**点赞**：

| 功能 | 说明 |
|------|------|
| 点赞动态 | 每人每条动态仅可点赞1次，再次点击取消 |
| 点赞数显示 | 实时显示点赞总数 |
| 点赞列表 | 点击点赞数可查看点赞用户列表 |

**转发/分享**：

| 功能 | 说明 |
|------|------|
| App内转发 | 转发到自己的动态主页（带"转发自@用户"标注） |
| 分享到微信 | 生成海报图片分享到微信好友/朋友圈 |
| 分享到QQ | 生成链接分享到QQ |
| 复制链接 | 复制动态页面链接 |

#### 3.3.4 认领流程

```
认领人点击"这是我的" 
  → 填写认领说明（描述物品特征以验证身份）
  → 提交认领申请
  → 发布者收到认领通知
  → 发布者审核认领申请（可查看认领人认证信息）
  ├── 同意 → 双方联系方式互相可见 → 线下归还
  │         → 归还确认（双方确认后状态变为"已归还"）
  └── 拒绝 → 认领人收到拒绝通知，可再次申请或申诉
```

**防冒领机制**：

- 认领时需填写物品独有特征验证（发布者设置验证问题）
- 认领人身份信息对发布者可见（学号+姓名+院系）
- 单条动态允许多人认领，由发布者最终确认

### 3.4 模块四：寻物动态

> 场景：我丢失了物品，想发布信息寻求帮助。

#### 3.4.1 寻物发布

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 物品分类 | 是 | 一级+二级分类选择 |
| 物品名称 | 是 | 简短描述，如"蓝色NorthFace双肩包" |
| 丢失描述 | 是 | 详细描述丢失经过和物品特征，10~500字 |
| 丢失地点 | 是 | 地图选点+文字描述 |
| 丢失时间 | 是 | 日期+时段选择 |
| 物品照片 | 否 | 如有同款照片可上传辅助识别，0~9张 |
| 感谢方式 | 否 | 口头感谢 / 请喝奶茶 / 感谢金（自填金额） |
| 联系方式 | 是 | 同失物发布 |
| 紧急程度 | 是 | 普通 / 加急（加急动态在首页优先展示） |
| 匿名发布 | 否 | 同失物发布 |

**发布流程**：同失物发布流程。

#### 3.4.2 寻物动态列表

展示形式与失物动态列表一致，增加以下元素：

| 元素 | 说明 |
|------|------|
| 紧急标签 | 加急动态显示红色"急"标签 |
| 感谢方式 | 展示感谢方式标签 |

#### 3.4.3 互动功能

与失物动态互动功能完全一致（评论、点赞、转发/分享）。

#### 3.4.4 提供线索

```
路人点击"我看到了/我捡到了"
  → 填写线索描述（在哪里看到/捡到的、当前状态等）
  → 上传照片（可选）
  → 提交线索
  → 失主收到线索通知
  → 失主与线索提供者通过私信沟通
  → 确认找回后标记"已找回"
```

#### 3.4.5 感谢与反馈

- 物品找回后，失主可发布"感谢动态"
- 可对帮助者进行感谢打赏（积分形式）
- 帮助者获得信用积分奖励

### 3.5 模块五：消息中心

#### 3.5.1 系统通知

| 通知类型 | 说明 |
|----------|------|
| 审核结果 | 发布的信息审核通过/未通过通知 |
| 账号相关 | 认证通过、密码修改、异地登录提醒 |
| 活动公告 | 平台活动、系统升级通知 |
| 违规警告 | 内容违规警告、账号处罚通知 |

#### 3.5.2 匹配提醒

| 通知类型 | 说明 |
|----------|------|
| 失物匹配 | 发布寻物后，有同类失物发布时推送匹配提醒 |
| 寻物匹配 | 发布失物后，有同类寻物发布时推送匹配提醒 |
| 附近动态 | 附近区域有新动态时推送提醒（可关闭） |

**智能匹配规则**：
- 分类相同 + 地点相近 + 时间吻合 → 高匹配度提醒
- 分类相同 + 地点相近 → 中匹配度提醒
- 分类相同 → 低匹配度提醒

#### 3.5.3 互动消息

| 通知类型 | 说明 |
|----------|------|
| 评论通知 | 有人评论我的动态 |
| 回复通知 | 有人回复我的评论 |
| 点赞通知 | 有人点赞我的动态 |
| 认领通知 | 有人申请认领我发布的失物 |
| 线索通知 | 有人提供寻物线索 |

#### 3.5.4 私信

| 功能 | 说明 |
|------|------|
| 发起私信 | 在动态详情页或用户主页点击"私信" |
| 消息类型 | 文字消息（最多500字）、图片消息 |
| 消息状态 | 已发送 / 已读 |
| 消息限制 | 非互关用户每天最多发起3次私信，防骚扰 |
| 拉黑 | 可拉黑用户，拉黑后无法互相私信 |
| 敏感词过滤 | 私信内容自动过滤敏感词 |

#### 3.6.2 我的发布

| 分类 | 说明 |
|------|------|

#### 3.6.4 收藏与足迹

| 功能 | 说明 |
|------|------|
| 收藏动态 | 收藏感兴趣的失物/寻物动态 |
| 浏览足迹 | 最近浏览的动态记录，最多保留100条 |

#### 3.6.5 信用积分体系

| 事件 | 积分变化 |
|------|----------|
| 实名认证通过 | +20 |
| 发布失物/寻物信息 | +5（每日上限3次） |
| 成功归还物品（发布者） | +30 |
| 成功找回物品（失主确认） | +20 |
| 提供有效线索 | +10 |
| 发布感谢动态 | +5 |
| 被举报且成立 | -20 |
| 冒领物品（查实） | -50 |
| 超时未处理认领申请 | -5 |

**积分等级**：

| 等级 | 积分范围 | 称号 | 权益 |
|------|----------|------|------|
| 1级 | 0~50 | 新人 | 基础功能 |
| 2级 | 51~150 | 热心同学 | 动态置顶1次/周 |
| 3级 | 151~300 | 校园达人 | 动态置顶3次/周 |
| 4级 | 301~500 | 失物克星 | 专属头像框 |
| 5级 | 500+ | 校园守护者 | 专属标识 + 优先客服 |

### 3.7 模块七：系统管理（管理员端）

#### 3.7.1 用户管理

| 功能 | 说明 |
|------|------|
| 用户列表 | 查看所有注册用户，支持按角色/院系/状态筛选 |
| 用户详情 | 查看用户认证信息、发布记录、违规记录 |
| 用户冻结 | 冻结违规用户账号，冻结期间无法登录 |
| 用户解冻 | 解除冻结 |
| 强制注销 | 永久注销严重违规用户账号 |
| 角色变更 | 将普通用户提升为管理员，或降级 |

#### 3.7.2 信息审核

| 功能 | 说明 |
|------|------|
| 待审核列表 | 新发布的失物/寻物信息，按提交时间排序 |
| 审核操作 | 通过 / 驳回（需填写驳回理由） |
| 批量审核 | 支持批量选中通过 |
| 审核标准 | 检查：信息完整性、照片清晰度、描述真实性、是否含敏感信息 |
| 审核时效 | 发布后24小时内完成审核 |

**自动审核规则**（减少人工审核压力）：

| 规则 | 处理 |
|------|------|
| 含有违禁词 | 自动驳回 |
| 照片模糊/不清晰 | 标记为需人工重点审核 |
| 同一用户短时间重复发布 | 标记为需人工审核 |
| 信息完整度高+信用积分高 | 自动通过（白名单机制） |

#### 3.7.3 举报处理

用户(User) 1 ──→ N 评论(Comment)
