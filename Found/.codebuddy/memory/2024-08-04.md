# 2024-08-04

## Icon 系统重构
- 将 Icon 组件从 Shape + Path 重写为 Image + SVG + colorFilter
- 根因: Shape 组件在 Flex 布局中尺寸不可控; `fillColor` 作用于 SVG fill(内部)而非 stroke(线条)
- 新方案: Image 渲染尺寸准确 → colorFilter 4x5 矩阵给线条染色(保留 alpha)
- 创建 `tint.ts` (hexToTint + TINT 常亮), `IconImage.ets` (52 图标 → Resource 映射)
- 批量更新 21 个文件, 48 处 Icon 调用: `color: $r('app.color.xxx')` → `tint: TINT.XXX`
- Login.ets 作为测试页面验证通过: 尺寸/位置/染色全部正常
