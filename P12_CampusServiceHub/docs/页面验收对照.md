# 校园服务枢纽 · 页面视觉验收对照表

> 用途：把 11 个页面的「应当长什么样」画成线框图，逐页对照实机运行结果做验收。
> 设计语言：Apple（DESIGN.md）。所有色值/圆角/间距均来自 `AppTheme` 单一来源，禁止硬编码。
> 视口：手机竖屏 360–480px（相对布局，宽度用 `%` / 栅格，无写死 px 宽度）。

---

## 图例（颜色 / 组件）

**色彩 Token（AppTheme.Colors）**
| 标记 | Token | 十六进制 | 用途 |
|------|-------|----------|------|
| ⬛ | black | `#000000` | 登录页沉浸深色背景 |
| ▫️ | bgLight | `#F5F5F7` | 浅色页面/浅色卡背景（无边框） |
| 🔵 | blue | `#0071E3` | Apple Blue 唯一强调色（按钮/链接/选中） |
| 🔹 | linkBlue | `#0066CC` | 浅底内联链接（协议文字） |
| ⬜ | white | `#FFFFFF` | 深底文本 / 蓝按钮文字 |
| ▌ | textDark | `#1D1D1F` | 浅底主文本 |
| ▍ | textSecondary | 黑 80% | 浅底次级文本 |
| ░ | textTertiary | 黑 48% | 浅底三级/禁用文本 |
| ◼️ | darkSurface | `#272729` | 海报占位深底块 |
| 🟦 | whiteTertiary | 白 48% | 深底三级文本（如登录副标题） |
| 🟥 | navBarBg | 黑 80% | 玻璃导航栏背景（0xCC000000） |

**组件约定**
- `AppCard`：无边框卡，浅色 `bgLight` / 深色 `darkSurface`，统一柔和阴影 `Radius.card=12` + 软阴影。
- `PrimaryButton`：🔵 蓝底白字，圆角 `8vp`（= DESIGN Primary Blue CTA 8px，正确）。
- `GlassNavBar`：顶部 🟥 玻璃栏（黑 80% + 模糊），48vp 高，标题白色；详情页带 ← 返回。
- 触摸目标：控件最小 **44×44vp**（服务页 ± 已修正为 44vp 满足规范）。

## 视觉一致性红线（比对时重点看）

1. **唯一蓝色**：所有交互色只能是 `blue #0071E3` / `linkBlue #0066CC` / `brightBlue #2997FF`。BMI 等级、活动状态、点赞态的「非激活」一律用灰（textTertiary/白48%），**不得出现红/绿/黄/橙**。
2. **无边框卡**：`AppCard` 无 border，靠 `bgLight`/`darkSurface` 底色 + 单一软阴影区分；**不得出现描边卡片**。
3. **CTA 圆角**：`PrimaryButton` 圆角 8vp（DESIGN 第4章 Primary Blue CTA 8px）。胶囊（980px 圆角）仅用于 Pill Link，本项目未使用。
4. **玻璃导航**：顶部栏为黑 80% 半透明 + 模糊，48vp 高；详情页带 ← 返回箭头（当前 32vp，属紧凑控件，不影响验收）。
5. **无硬编码**：页面/组件不得直接写 `0x######`，一律引用 `Colors.*`（已修正 GlassNavBar 的 `0xCC000000`→`Colors.navBarBg`）。
6. **触摸目标**：可点控件 ≥44×44vp（服务页 ± 已为 44vp）。
