# 鸿蒙 ArkTS 电商价格监控 "PriceHound" App —— 项目规划书与功能介绍

## 一、项目背景

电商平台价格波动频繁，“先涨后降”的虚假促销套路普遍存在。消费者缺乏有效工具来追踪商品的历史价格、跨平台比价和识别真正的低价时机。市面上虽有慢慢买、什么值得买等应用，但大多依赖爬虫技术，存在法律风险。

本项目旨在基于**鸿蒙 ArkTS** 开发一款合规、隐私友好的电商价格监控应用，帮助用户做出更明智的购物决策。

## 二、项目目标

| 目标 | 描述 |
| :--- | :--- |
| **核心功能** | 商品价格追踪、历史走势图、历史低价识别、跨平台比价 |
| **隐私保护** | 用户数据本地存储，不上传云端 |
| **鸿蒙原生** | 纯血鸿蒙应用，适配 ArkTS + HarmonyOS NEXT |

## 六、实施路线图

- [ ] 鸿蒙项目初始化，搭建基础框架

- [ ] 用户数据导出功能

## 七、风险与应对

| 风险 | 应对策略 |
| :--- | :--- |
| **数据源不稳定** | 采用多数据源 fallback 架构，一个源失败自动切换 |
| **官方 API 申请困难** | MVP 阶段先用第三方数据服务，后期逐步接入官方 API |
| **成本控制** | 第三方 API 按调用计费，初期控制监控频率和商品数量 |
| **合规风险** | **坚决不使用爬虫**，仅使用官方 API 和授权第三方服务 |
| **鸿蒙生态不成熟** | 参考鸿蒙官方文档，关注社区动态，核心逻辑保持跨平台可移植性 |

# 九、主要功能介绍（详细）

## 9.1 商品管理

### 9.1.1 商品搜索与添加
- 支持通过**商品链接**（淘宝、京东、拼多多等主流平台）一键添加追踪商品
- 支持**关键词搜索**，快速查找目标商品并添加到监控列表
- 自动识别商品信息（名称、图片、当前价格、平台来源），无需手动录入
- 支持**扫码**添加（扫描商品条形码/二维码）

### 9.1.2 商品分类与标签
- 自定义**分类管理**（如数码产品、家用电器、日常消耗品等）
- 支持给商品添加**自定义标签**（如“想买”、“观望”、“已降价”等）
- 支持**收藏/置顶**重要商品，优先关注

### 9.1.3 批量管理
- 批量导入/导出商品列表（支持 CSV 格式）
- 批量删除、批量暂停监控等管理操作

---

## 9.2 价格追踪与监控

### 9.2.1 智能定时监控
- 后台**自动定时**（可自定义频率：每小时/每天/每周）抓取商品最新价格
- 支持**手动刷新**，随时获取实时价格
- 监控状态可视化，清晰显示每个商品的监控状态（监控中/已暂停/异常）

### 9.2.2 价格变动记录
- 完整记录每次价格变动的时间、价格、变动幅度
- 自动计算**涨跌百分比**和**变动趋势**（上涨/下跌/持平）
- 支持按时间范围筛选查看价格变动历史

### 9.2.3 多平台比价
- 同一个商品（如 iPhone 15），自动抓取**淘宝、京东、拼多多等多个平台**的价格
- 直观对比各平台**当前最低价**及**历史最低价**
- 显示各平台的**价格优势排名**，推荐最优购买渠道

---

## 9.3 价格分析与可视化

### 9.3.1 价格走势图
- 以**折线图**形式直观展示商品价格的历史变化趋势
- 支持按**日/周/月/季/年**不同时间维度查看走势
- 图表中清晰标注**历史最高点**和**历史最低点**
- 支持图表**缩放与拖动**，查看任意时间段的细节

### 9.3.2 历史低价识别
- 自动标记该商品的**历史最低价**及出现时间
- 计算**当前价格与历史最低价的差距**（差价/百分比）
- 显示**平均价格**、**中位数价格**等统计指标
- **“先涨后降”假促销识别**：自动检测商品是否在促销前大幅涨价再打折

### 9.3.3 价格预测
- 基于历史数据，利用简单算法（如移动平均）预测**近期可能的价格走势**
- 提供**购买建议**（“当前价格位于历史低位，建议入手” / “价格处于高位，建议观望”）
- 显示**降价概率**和**预估降价幅度**

---

## 9.4 降价提醒与通知

### 9.4.1 智能降价提醒
- 用户可设置**目标价格**，当商品价格降至目标价时自动发送通知
- 支持设置**降价幅度提醒**（如“再降 5% 时通知我”）
- 支持设置**绝对价格提醒**（如“低于 1000 元时通知我”）

### 9.4.2 多种通知方式
- 鸿蒙系统**本地推送通知**（锁屏/通知栏提醒）
- 支持**每日/每周价格汇总报告**推送
- 通知内容包含商品名称、当前价格、降价金额及直达链接

### 9.4.3 通知管理
- 支持按商品单独设置/关闭提醒
- 通知历史记录查看
- 免打扰时段设置

---

## 9.5 数据看板与统计

### 9.5.1 总览看板
- 今日价格变动商品数量及变动幅度汇总
- 当前正在监控的商品总数
- 历史累计节省金额估算（（历史低价 - 实际购入价）的总和）
- 近 7 天价格变动最频繁的商品 Top 榜

### 9.5.2 省钱统计
- 统计用户在哪些商品上买到了“历史低价”
- 生成**省钱报告**（月度/季度/年度）
- 对比“当前价购入”vs“历史低价购入”的差异金额

### 9.5.3 市场行情
- 热门商品价格趋势汇总
- 各平台整体价格水平对比分析

---

## 9.6 个人中心与设置

### 9.6.1 数据管理
- **本地数据优先**：所有价格历史数据存储在手机本地 SQLite，保障隐私安全
- 支持**数据导出**（导出为 CSV/Excel 格式，便于 Excel 中分析）
- 支持**数据备份与恢复**（本地备份或云备份）

### 9.6.2 监控设置
- 全局监控频率设置（节省电量和流量）
- 数据源优先级配置（优先使用官方 API 还是第三方 API）
- 单个商品的监控开关

### 9.6.3 通知设置
- 全局通知开关
- 通知声音/震动设置
- 每日报告推送时间设置

### 9.6.4 其他设置
- 主题切换（深色/浅色模式）
- 多设备数据同步（鸿蒙生态）
- 应用锁（保护隐私数据）
- 关于与反馈
