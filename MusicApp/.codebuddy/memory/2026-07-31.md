## 图标染色方案定型：Image + colorFilter（替换 inline Path 方案）
- 需求：用户要求把图标染色方式改为 `Image` 的 `.colorFilter`，移除原先的 inline `Path` + `stroke` 染色逻辑；所有图标组件统一用该方法上色。
- 实现：在 `components/common.ets` 新增导出函数 `tintMatrix(color: string): number[]`，把十六进制颜色转成 4x5 染色矩阵（20 元素，偏移量范围 **0..255**），`IconSlot` 改为 `Image(this.icon).colorFilter(tintMatrix(this.fg))`。
- 矩阵原理：RGB 乘子全 0、第 5 列常数偏移=目标色(R,G,B)、alpha 行 `0,0,0,1,0` 保留透明度 → 描边被染色，中间（无像素）保持透明，**不会填实**（outline SVG 本身 `fill=none`）。
- 关键点：`Image.colorFilter()` 直接接受 `number[]`（CSDN 详解确认 `ColorFilter | number[]`），无需 `new ColorFilter`；偏移量用 0..255（Start.ets 的 logo 矩阵 `29,185,84`=#1DB954 即佐证）。
- 同步改动：`Mine.ets` 的 star（`fillColor(Colors.accent)`→`colorFilter(tintMatrix(Colors.accent))`）、`Start.ets` 跳过图标与 logo 也改用 `tintMatrix`（跳过图标颜色改为 `Colors.textPrimary` 与文字一致，logo 仍 `#1DB954`）。
- 清理：删除 `theme/iconPaths.ets`（旧 inline Path 方案的路径注册表），移除 `scalePath`/`iconName` 残留。
- 调用方状态：本工程文件易被还原（此前多次 common.ets 等被还原回原始态）。当前调用方均为原生的 `icon: $r(...)` 形式 + `TabType.icon?: Resource` + `modeIcon(): Resource`，恰好契合 colorFilter 方案，无需改调用方。
