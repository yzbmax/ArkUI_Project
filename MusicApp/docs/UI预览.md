# 黑马云音乐 · 页面 UI 预览（线框稿）

> 依据 `docs/PRD.md`（F01–F10）+ `docs/DESIGN.md`（Spotify 暗色体系）绘制。
> 配色 token：`bg #121212` / `surface #181818` / `surfaceMid #1f1f1f` / `text #ffffff` / `text2 #b3b3b3` / `accent #1ed760`。
> 说明：线框中 ▢ = 封面占位色块（Mock 用 color 填充，零网络依赖）；● = 圆形按钮；▭ = 卡片/面板。

## 1. 启动页 Start（F01）

倒计时 5s 自动进入首页，右上胶囊「跳过 5s」，不可返回。

```
┌──────────────────────────────┐
│                     ┌────────┐ │
│  ●                  │跳过 5s │ │   ← 右上胶囊按钮（9999px，surfaceMid）
│                     └────────┘ │
│                                │
│           ┌────────┐           │
│           │   ▢    │           │   ← 居中 Logo 占位（绿色描边圆/方）
│           │ 音 乐  │           │
│           └────────┘           │
│                                │
│            黑马云音乐           │   ← 标题 700，白色
│        HARMONY MUSIC           │   ← 副标 caption，银色
│                                │
│      ┌────────────────┐        │
│      │  ◍ 进度环 5→0   │        │   ← 倒计时进度环（可选）
│      └────────────────┘        │
└──────────────────────────────┘
           背景 bg #121212
```

**要点**：Logo 居中；跳过胶囊右上固定；5s 倒计时或点击跳过 → `replaceUrl('pages/Index')`。

## 4. 发现页 Find（F04）

```
┌──────────────────────────────┐
│ 发现                           │   ← 24px 700
│ ┌──────────────────────────┐  │
│ │ 🔍  搜索歌曲、歌手…        │  │   ← 胶囊搜索框（surfaceMid, 500px）
│ └──────────────────────────┘  │
│ ┌──┐ 歌名A             ▶      │   ← ListItem：封面+标题+作者
│ │▢ │ 歌手A                     │
│ ├──┤ 歌名B             ▶      │
│ │▢ │ 歌手B                     │
│ ├──┤ 歌名C             ▶      │
│ │▢ │ 歌手C                     │
│ ├──┤ 歌名D             ▶      │
│ │▢ │ 歌手D                     │
│ └──┘ …（LazyForEach）          │

       [ Mini-Bar 常驻 ]
```

**要点**：点击 `pushUrl('pages/Play')` + `AVPlayerManager.singPlay(item)`；列表渲染正确、触发播放跳转。

## 7. 播放页 Play（F07）— 核心

唱片旋转 + 唱针 + 进度 Slider + 控制 + 播放列表面板（左滑删）。

```
┌──────────────────────────────┐
│  ✕  正在播放            ≡列表 │   ← 顶部：关闭 + 列表入口
│                                │
│          ╱﹋﹋╱                │
│        ╱ 唱针 ╲   ← 摆动唱针    │
│       │   ●    │               │
│   ┌───────────────┐            │
│   │    ▢ 唱片旋转   │           │   ← Animator 旋转（暂停时停）
│   │     (圆形)     │           │
│   └───────────────┘            │
│                                │
│   歌名（700）                   │   ← 标题
│   歌手（400 银色）              │
│                                │
│   ├───────────●──────────┤     │   ← Slider 进度条 accent 绿
│   01:23              03:45     │   ← 当前/总时长 caption
│                                │
│      🔀    ⏮    ●▶    ⏭    🔁   │   ← 随机/上一/播放暂停/下一/模式
│                                │   ← 模式三态：auto/repeat/random
│   ┌────── 播放列表面板 ──────┐  │
│   │ ▢ 歌名1  歌手1        ✕ │  │   ← swipeAction 左滑删除
│   │ ▢ 歌名2  歌手2        ✕ │  │
│   │ ▢ 歌名3  歌手3        ✕ │  │
│   └──────────────────────────┘ │   ← 高度 0%↔100% 动画
└──────────────────────────────┘
```

**要点**：旋转/暂停联动；进度实时更新；模式三态切换；列表面板增删正确（swipeAction）。

## 10. 全局设计约束速查

| 维度 | 取值（取自 AppTheme token，禁止硬编码） |
|---|---|
| 背景 | `Colors.bg #121212`（页面）/ `Colors.surface #181818`（卡片） |
| 文本 | `Colors.textPrimary #ffffff` / `Colors.textSecondary #b3b3b3` |
| 强调 | `Colors.accent #1ed760`（仅播放控制/激活态/CTA） |
| 圆角 | 卡片 8px / 胶囊 9999px / 圆形 50% |
| 阴影 | 卡片 `Shadow.card` 0.3 / 弹层 `Shadow.heavy` 0.5 |
| 字号 | 标题 24 / 区块 18 / 正文 16 / 标注 14 / 小字 12 / 微 10 |
| 按钮 | 全胶囊；播放键圆形；英文大写 + 字距 1.4–2px |
| 栅格 | 8px 基准；平板 2 列；移动优先 |
