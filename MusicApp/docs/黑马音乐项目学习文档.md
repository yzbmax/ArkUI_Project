# HarmonyOS音乐应用项目学习文档

## 项目概述

这是一个基于HarmonyOS开发的音乐播放器应用，名为"黑马音乐"。项目实现了音乐播放、推荐歌单、发现音乐、动态分享等核心功能，是一个完整的HarmonyOS应用开发示例。

### 主要功能
- **启动页**：5秒自动跳转到主页面
- **推荐页**：轮播图、每日推荐、推荐歌单
- **发现页**：歌曲列表展示
- **动态页**：用户分享的音乐动态
- **我的页**：个人收藏和播放列表
- **播放页**：音乐播放控制界面
- **网络请求**：从服务器获取音乐数据
- **媒体播放**：使用AVPlayer播放音乐

#### 装饰器说明
- `@Entry`：标记为入口组件
- `@Component`：标记为自定义组件
- `@State`：组件内部状态，变化会触发UI更新
- `@StorageProp`：从AppStorage中读取数据，单向同步
- `@StorageLink`：从AppStorage中读取数据，双向同步
- `@Prop`：从父组件传递的数据，单向同步

### 4. 网络请求模块

#### API配置（apis/index.ets）
```typescript
import { http } from '@kit.NetworkKit';

const baseUrl = 'http://192.168.1.100:3000';  // 服务器地址

export const getData = async (path: string) => {
  const req = http.createHttp();
  try {
    const res = await req.request(baseUrl + path, {
      expectDataType: http.HttpDataType.OBJECT,
    });
    req.destroy();
    return res.result;
  } catch(error) {
    req.destroy();
    uiContext.showAlertDialog({ message: '无法请求网络数据' });
    throw new Error(`无法请求网络数据：${error.code} ${error.message}`);
  }
}

// 具体的API接口
export const getSwiper = async () => {
  return await getData('/data/swiper');
}
export const getDailyRecommend = async () => {
  return await getData('/data/dailyRecommend');
}
```

    { icon: $r('app.media.ic_mine'), text: '我的', name: 'mine' }

  build() {
    Column() {
      // 内容区域：根据当前激活的标签显示不同组件

        Recommend()
      } else if (this.isActive === 'find') {
        Find()
      } else if (this.isActive === 'moment') {

      } else {
        Mine()

    }
  }
}

## 学习要点总结

### 1. HarmonyOS开发基础
- **ArkTS语法**：TypeScript的超集，支持装饰器语法
- **ArkUI组件**：声明式UI开发，类似React/Flutter
- **状态管理**：@State、@Prop、@Link、@StorageProp、@StorageLink的区别和使用场景
- **组件生命周期**：aboutToAppear、aboutToDisappear、onPageShow等

### 2. 项目架构设计
- **模块化组织**：apis、models、utils、views分离
- **数据模型设计**：接口定义 + 类实现
- **网络请求封装**：统一的请求处理和错误处理
- **媒体播放管理**：AVPlayer的封装和状态管理

### 3. HarmonyOS特有功能
- **Ability系统**：UIAbility作为应用入口
- **权限管理**：在module.json5中声明所需权限
- **资源管理**：使用$r()引用资源
- **路由导航**：使用router进行页面跳转

### 4. 开发注意事项
1. **网络权限**：必须在module.json5中声明`ohos.permission.INTERNET`
2. **页面注册**：所有页面必须在main_pages.json中注册
3. **状态管理**：合理选择状态装饰器，避免不必要的渲染
4. **错误处理**：网络请求需要有完善的错误处理机制
5. **资源引用**：使用$r('app.media.xxx')引用图片资源

### 5. 项目调试要点
1. **服务器地址**：API中的baseUrl需要根据实际服务器修改
2. **模拟数据**：mock目录可用于本地数据模拟
3. **设备兼容**：注意不同设备的屏幕适配
4. **性能优化**：避免在build方法中进行复杂计算
